# 洪拳割草 (Hung Kuen Hordes)

一款以洪拳为主题的俯视角「割草」类 HTML5 小游戏。

灵感来自暖雪 / 吸血鬼幸存者（Vampire Survivors）：
你在战场上自动出手清掉成片涌来的敌人，拾取「气」经验、升级并从**洪拳招式**中三选一不断变强，最终击败关底 Boss「山贼头目」。

- **源码**：<https://github.com/13413183976txy-debug/hung-kuen-hordes>（公开仓库，随时可克隆/部署）
- **在线试玩**：<https://13413183976txy-debug.github.io/hung-kuen-hordes/>（GitHub Pages，HTTPS；推送 `main` 即自动重新构建，约 1 分钟生效）
- 纯 HTML + Canvas 2D + 原生 JS（ES Modules），**零依赖、零构建**。

## 玩法一览

- **移动**：WASD / 方向键；最后一次移动方向即角色朝向；行走为**定向动画**（左右侧面 4 帧/上背面/下正面，素材已去底去水印）。
- **普通攻击 `J`**：按住自动连击（按冷却节流）；**自动索敌：无论朝向，攻击范围内最近的一名敌人**（单体，出拳自动转向，目标身下有金色锁定圈）；范围内无目标时空挥（不消耗正式冷却）。普攻期间可正常移动。
- **水波大招 `K`（惊涛叠浪）**：以主角为圆心 360° 清场（冷却 6s；施放时仅 0.4s 定身，无长期压制；HUD 右侧显示「调息」倒计时，就绪时金色呼吸+亮起）。
- **暂停 / 静音**：`Esc` 暂停/继续（世界完全冻结）；`M` 静音切换（HUD 左下角显示状态）。
- **敌人技能**：大刀兵快刀前摇；锤兵砸地前有朱砂落地预警圆（移开即免伤）；Boss 三阶段行为不同（一阶段近战斩 → 二阶段蓄力冲锋 → 三阶段红扇形斩），每个技能都有蓄力预警 → 有效帧 → 收招硬直。玩家受击为**阻尼击退滑步**（位移渐变、重击最远约 120px），不会被直接击飞。
- **核心循环**：清怪 → 掉「气」珠 → 升级三选一成招 → **击杀关底 Boss「山贼头目」即胜利**（Boss 波不按时间结束；结算页含关底状态/普攻总伤/绝技次数/最高一击/前三招式）。

## 角色 / 敌人（素材定稿）

| 角色 | 素材（assets/sprites） | 定位 |
|---|---|---|
| 主角 | `hero/*`（蓝衣洪拳弟子） | 玩家 |
| 大刀兵 | `blade/*`（黄衣快刀） | 普通杂怪（量大、脆） |

## 运行方式

任选其一：

- **Windows**：双击 `启动游戏.bat`（自动探测端口 → `python -m http.server` 起服 → 打开浏览器）。
- **任意平台**：在仓库根目录执行 `python -m http.server 8080` 或 `npx http-server`，浏览器打开 <http://127.0.0.1:8080>。
- **注意**：`js/` 内是 ES Modules，**`file://` 双击打开会被部分浏览器阻止**，请始终走 HTTP。
- 部署到任意静态托管（GitHub Pages / Vercel / Netlify）均开箱即用，无需构建。

> **常见问题：脚本加载失败 / 白屏 / 旧行为**：按 `Ctrl+F5` 强制刷新。所有模块带 `?v=NN` 缓存版本号，改动 `js/` 后请全量递增（如 `?v=16` → `?v=17`），否则浏览器可能混用新旧缓存模块。

## 难度与设计目标

- **常规**：允许约 4～6 次普通失误；走位与 K 解围是核心，新玩家掌握后应大概率通关。
- **修罗**：允许约 2～3 次普通失误；要求主动躲 Boss 技能。修罗倍率：敌人生命 ×1.15、伤害 ×1.12、经验 ×1.05、Boss 技能冷却 ×0.90；Boss 二/三阶段预警缩短 12%；第四波存活上限 +2；Boss 波每 9 秒刷 1 名大刀兵（最多 2，无锤兵）；**不提高任何普通敌人移速**。
- **原则**：任何敌人伤害都必须可预警、可躲避、可学习；K 大招代价仅为 0.4s 定身（无长期弱化）。
- **开发辅助**：按 `F3` 显示/隐藏平衡面板（波次·存活数 / DPS 估算 / 近 10s 受创 / 等级·已选升级 / K 冷却 / Boss 阶段与技能状态）。
- **个人纪录（localStorage）**：最快斩首时间、最多斩敌、最高等级、通关次数；标题页底部低调展示；破纪录时胜利页盖金色“新纪录”印。
- **偏好持久化**：静音（M）、减少震动、难度、首局引导标记均存入 localStorage，刷新保留。

## 手动测试清单

1. 启动：仓库根目录执行 `python -m http.server 8080`（或双击 `启动游戏.bat`），浏览器打开 `http://127.0.0.1:8080`。
2. 标题页：主副标题、圆形“洪”字印章、三行说明各占一行；落叶/尘粒缓慢飘动；按钮 hover 上浮并发金色外光。
3. `开 始 游 戏` 后 WASD 移动：左上“气血/内息”卷轴条、右上“战局/斩敌/波次/绝技K”实时刷新；脚下有金色朝向扇形提示。
4. 站入怪群：**按住** `J` 连续出拳（无需反复按键），自动锁定范围内最近的敌人（无论走哪个方向，出拳时自动转向目标）；空挥有拳风与风声且不消耗冷却。观察扇形拳风弧光、白黄火星、伤害数字、暴击朱砂爆裂与震屏顿帧。按 `K` 释放 360° 环形水波大招「惊涛叠浪」（三层扩散环 + 强制暴击，施放时短暂定身，HUD 显示调息冷却）。
5. 升级弹窗“武学精进”：三张竖卷轴卡（类别标签 + 招式印记 + 名称 + **Lv.n → n+1** + 本次实际变化数值），hover 上浮金边墨晕，点击朱砂闪光；可选也可按 1/2/3。前三次升级优先基础输出/攻速/范围/生存，不会出现纯大招卡。
6. 选招后回战场，金色气劲环绕汇聚到角色身上。
7. 约 2 分钟进入 Boss 波：出现“山贼头目”专属血条、阶段提示（一·蓄势 / 二·暴起 / 三·搏命）与“目标 · 击败山贼头目”提示；Boss 波**只出 Boss、不再刷小兵**（场上残留杂兵仍会清完），且不按时间结束，**击杀 Boss 后杂兵清场淡出 → 胜利**。
8. 小兵来源：普通波的小兵一律从**地图（草坪）边缘**刷出（上/下/左/右随机一边），随后直线逼近主角——不会贴着屏幕边缘闪现。
9. 死亡/胜利：分别出现“败北”（朱砂）与“胜利”（鎏金）结算页，战局/斩敌/修为三格数据正确，“再战一场/再试一次”可重新开局。
10. 其余手感检查：敌人不会叠在玩家脚下（有间距与攻击距离边缘停顿）；首次出手时间随机错开，无敌帧防止贴脸多段爆发；气血低于 28% 时“气血”标签朱砂脉动提醒。
11. 技能可读性：预警从 windup 开始立即出现、颜色随剩余时间由淡朱砂变亮朱砂、二次描边不被大招遮住。刀兵前摇 0.18s（轻扇形）；锤兵 0.48s 扬锤 + 朱砂落点圆（离开免伤，落地尘土环，0.70s 硬直）；Boss 近战 0.28s（范围 185 长于主角 150，先手优势）、冲锋 0.35s 蓄力 + 0.95s 扑空硬直（主要输出窗口）、血刃 0.62s 蓄力 + 0.85s 收招；Boss HP 3200。
12. 数值基调：主角 HP170/速度245/攻速0.32s/普攻 36（基础，可被「虎形连环」等加成）/无敌0.65s；敌人速度均低于主角（205/175/215），基础伤害 6/18/24 随波次 ×1.00→1.14 轻微递增（Boss 波恒为 1.00）；K 冷却 6s，代价仅为 0.4s 定身。
13. 系统操作：`Esc` 暂停/继续（暂停页含按键说明/重看操作/音效/减少震动/重新开始）；切出窗口自动暂停（回来需手动继续）；`M` 静音并持久化，HUD 左下角显示状态。
14. 首局引导：仅首次开局依次显示三条提示（WASD 游走避敌 / 按住 J 自动连击 / K 水波破围），每条 ≤2.5s，任意移动/攻击键提前切下一条；暂停菜单可“重看操作”。
15. 结算页：胜负均显示 难度 / 战局 / 斩敌 / 修为 / 关底状态 / 普攻总伤 / 绝技释放次数 / 最高一击 / 前三招式 / 个人最佳；破纪录盖金色“新纪录”；胜利提供 再战一场 / 同难度再战 / 返回标题，失败提供 再试一次 / 返回标题。
16. 攻击距离已缩短至主角模型附近（120 + 敌人半径贴身判定）；受击仅短暂阻尼滑步，屏幕边缘朱砂闪烁 ≤0.18s。

## 设计规范速记

- 五色：墨黑 `#17130F`、宣纸米白 `#E9D7AA`、朱砂红 `#B5362D`、鎏金 `#D6A84A`、竹青 `#50705A`。
- 标题用楷体系（STKaiti/KaiTi/FangSong），正文用 Microsoft YaHei。
- 界面：深墨半透明面板 + 细金描边 + 朱砂点缀 + 宣纸噪点；无 Emoji、无大圆角卡片。
- 精灵素材已去除 AI 水印/文字残留；原始抠图源图（部分带极淡平台水印）保留在本地 `img/` 且已加入 `.gitignore`，**不入库**。
- 素材处理与调试工具在 `tools/`（抠图去白边 / 拼 Sheet / 检查表生成），游戏运行时不加载。
